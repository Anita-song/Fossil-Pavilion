# Fossil-Pavilion
El Pabellón "Fósil" simula un hallazgo arqueológico que emerge del suelo. Su diseño usa costillas de madera curva que evocan una caja torácica y paredes que simulan estratos de tierra. Al recorrer su sendero en "S", la alternancia de luz y sombra genera una experiencia de descubrimiento progresivo, invitando al visitante a sentir que desentierra el espacio a escala humana.
